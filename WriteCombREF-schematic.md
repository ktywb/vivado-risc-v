  │  │  ┌────────────────────────────────────────────────────┐        │   │

  │  │  │                                                     │        │   │

  │  │  │  Shift left: 0x1234 << 64 bits                     │        │   │
  │  │  │                                                     │        │   │
  │  │  │  Result:   [0x12][0x34]...[0xAA][0xBB]            │        │   │

  │  │                                                                 │   │

  │  │                : isGt    ? s2_data        (旧缓存)            │   │
  │  │                : isEq    ? s3_dataCat     (合并)              │   │
  │  │                : 0                        (不输出)             │   │
  │  │                                                                 │   │
  │  │  s3_infoOutput = [根据情况选择 infos 数组]                    │   │
  │  └────────────────────────────────────────────────────────────────┘   │
  │                                                                         │
  │  ┌────────────────────────────────────────────────────────────────┐   │
  │  │              BRAM Write Operations                              │   │
  │  │                                                                 │   │
  │  │  when(s2_valid && s3_ready && !s2_stepGq) {                    │   │
  │  │    dataBRAM.write(s2_hash, s3_dataWriteData)                   │   │
  │  │  }                                                              │   │
  │  │                                                                 │   │
  │  │  when(s3_infoWriteEnable[i]) {                                 │   │
  │  │    infoBRAMS[i].write(s2_hash, s3_infoWriteData[i])            │   │
  │  │  }                                                              │   │
  │  └────────────────────────────────────────────────────────────────┘   │
  │                                                                         │
  │  ┌────────────────────────────────────────────────────────────────┐   │
  │  │              Output Valid Control                               │   │
  │  │                                                                 │   │
  │  │  s3_valid = (drain && s2_fillRate > 0)                         │   │
  │  │           || (s2_stepGq || s2_isGt || s2_isEq)                 │   │
  │  └────────────────────────────────────────────────────────────────┘   │
  │                                                                         │
  │  Output: s3_valid, s3_hash, s3_data, s3_num, s3_infos, s3_validbytes │
  └─────────────────────────────┬───────────────────────────────────────────┘
                                │
                                ▼
                          ┌──────────┐
                          │ io.out   │
                          └──────────┘
```

│  └────────┘   │                         │                                 │
│               │                         │ RegNext                         │
│               │                         ▼                                 │
│               │               ┌──────────────────┐                        │
│               │               │s2_hazardFillRate │                        │

## 7. 控制逻辑状态机

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                      Control State Machine Diagram                        ║
╚═══════════════════════════════════════════════════════════════════════════╝

                    ┌──────────────────────────────────┐
                    │         Power On Reset           │
                    └───────────────┬──────────────────┘
                                    │
                                    ▼
            ┌───────────────────────────────────────────────┐
            │               sInit / sBuild                  │
            │        (Initialization State)                 │
            ├───────────────────────────────────────────────┤
            │  Purpose: 清空所有 BRAM                       │
            │                                               │
            │  ┌─────────────────────────────────────┐     │
            │  │  for (initCounter = 0;              │     │
            │  │       initCounter < partition_num;  │     │
            │  │       initCounter++) {              │     │
            │  │    numBRAM[counter] = 0;            │     │
            │  │    fillRateBRAM[counter] = 0;       │     │
            │  │    dataBRAM[counter] = 0;           │     │
            │  │    for (i=0; i<Batchs; i++)         │     │
            │  │      infoBRAMS[i][counter] = 0;     │     │
            │  │  }                                  │     │
            │  └─────────────────────────────────────┘     │
            │                                               │
            │  Exit: when initCounter == partition_num     │
            │        set init_done = true                   │
            └────────────────┬──────────────────────────────┘
                             │
                             ▼
            ┌───────────────────────────────────────────────┐
            │                  sPre                         │
            │             (Pre-work State)                  │
            ├───────────────────────────────────────────────┤
            │  Transition to sWork                          │
            └────────────────┬──────────────────────────────┘
                             │
                             ▼
            ┌───────────────────────────────────────────────┐
            │                  sWork                        │
            │            (Working State)                    │
            ├───────────────────────────────────────────────┤
            │  Accept input tuples via io.in               │
            │                                               │
            │  For each tuple:                              │
            │  1. Hash to partition                         │
            │  2. Read current state (num, fillRate)        │
            │  3. Determine action (stepGq/isGt/isEq/isLt)  │
            │  4. Update BRAM                               │
            │  5. Output if full                            │
            │                                               │
            │  ┌─────────────────────────────────────┐     │
            │  │  while (input_available) {          │     │
            │  │    hash = input.hash;               │     │
            │  │    [Read BRAM]                      │     │
            │  │    [Calculate]                      │     │
            │  │    [Update BRAM]                    │     │
            │  │    if (should_output)               │     │
            │  │      output_data();                 │     │
            │  │  }                                  │     │
            │  └─────────────────────────────────────┘     │
            │                                               │
            │  io.in.ready = true                           │
            │  busy = s1_valid || s2_valid || s3_valid     │
            └────────────────┬──────────────────────────────┘
                             │
                             │ External trigger
                             ▼
            ┌───────────────────────────────────────────────┐
            │                 sDrain                        │
            │            (Drain State)                      │
            ├───────────────────────────────────────────────┤
            │  Purpose: 输出所有未满的缓冲区                │
            │                                               │
            │  ┌─────────────────────────────────────┐     │
            │  │  for (drainCounter = 0;             │     │
            │  │       drainCounter < partition_num; │     │
            │  │       drainCounter++) {             │     │
            │  │    if (fillRateBRAM[counter] > 0) { │     │
            │  │      output(dataBRAM[counter],      │     │
            │  │             fillRateBRAM[counter],  │     │
            │  │             numBRAM[counter]);      │     │
            │  │      // Clear BRAM                  │     │
            │  │      numBRAM[counter] = 0;          │     │
            │  │      fillRateBRAM[counter] = 0;     │     │
            │  │    }                                │     │
            │  │  }                                  │     │
            │  └─────────────────────────────────────┘     │
            │                                               │
            │  io.in.ready = false (不接受新输入)          │
            │                                               │
            │  Exit: when drainCounter traversed all       │
            │        and pipeline empty (!s1/s2/s3_valid)  │
            │        set drain_done = true                  │
            └────────────────┬──────────────────────────────┘
                             │
                             ▼
                    ┌────────────────┐
                    │   sIdle / End  │
                    └────────────────┘


状态转换条件:
───────────────────────────────────────────────────────────────
  sInit  →  sPre     : initCounter == partition_num
  sPre   →  sWork    : External trigger
  sWork  →  sDrain   : External trigger
  sDrain →  sInit    : Restart / Reset
───────────────────────────────────────────────────────────────
```
